# Nibtree UI components

Generated from `ui/web/src/lib/docs/` by `bun run ui:docs`; do not edit by hand. Every component takes its colors from
the theme tokens and its sizes from `ui/design-tokens/`, and none takes a class or style: everything is a prop. Lay out
screens with Stack and write words with Text. Import a component from `@nibtree/ui/components/<Name>.svelte` (the local
package; `$ui/...` inside the showcase); each one has its own page in `docs/components/`, and each group's page says in
a line what every component is for.
